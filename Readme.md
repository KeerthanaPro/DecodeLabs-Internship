# AI Recommendation Logic

## Overview

This project is a simple AI Recommendation System developed as part of the DecodeLabs Internship. It recommends items based on the user's interests using basic pattern matching and logical conditions.

## Features

- Takes user interests as input
- Matches preferences using predefined logic
- Displays personalized recommendations
- Easy to extend with more categories

## Technologies Used

- Python

## How to Run

```bash
python recommendation.py
```

- Logic Building
- Pattern Matching
- User Input Handling
- Recommendation Concepts
